Panduan Deploy ke Vercel (Siap Pakai)

Aplikasi ini dirancang dengan arsitektur Single-File Vanilla JS sehingga bisa langsung di-hosting ke Vercel secara gratis tanpa error build:

  1. Simpan kode ini di komputer Anda dengan nama index.html di dalam sebuah folder (misal: bekas-berkelas/).
  2. Buka vercel.com atau push folder tersebut ke repositori GitHub Anda.
  3. Import project di Vercel, biarkan Framework Preset: Other, lalu klik Deploy.
Catatan Penyimpanan:
Seluruh foto yang Anda upload dikonversi otomatis menggunakan kompresi Canvas Base64 dan disimpan di localStorage browser sehingga ringan dan langsung tampil.
